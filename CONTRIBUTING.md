# Contributing to N-ATLAS Forge

Thank you for your interest in contributing to N-ATLAS Forge.

Before starting a major change, please open an issue describing the problem or feature you would like to work on.

## Getting Started

Fork the repository and create a new branch for your changes.

```bash
git checkout -b feature/your-change
```

Install the project dependencies, configure the required environment variables using `.env.example`, and run the project locally.

## Making Changes

Keep changes focused and consistent with the existing project structure. Test your changes before submitting them and make sure they do not introduce unrelated changes.

Do not commit API keys, passwords, tokens, `.env` files, or other sensitive information.

## Pull Requests

Push your branch and open a pull request against the `main` branch.

Please explain what was changed, why the change was needed, and include any relevant screenshots or testing information.

## Bug Reports

When reporting a bug, include the affected feature, steps to reproduce the problem, expected behavior, actual behavior, and any relevant error messages.
